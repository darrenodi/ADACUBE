# Decisions

## Made

- **Stack**: C++ + Python + TypeScript, with PostgreSQL. Java not chosen as the foundation because the key CAD and simulation libraries are native C++.
- **Play behaviour**: real engineering simulation driving the visual animation (not animation alone).

## Open

- **Platform**: desktop, web, or both eventually.
- **Scope of internal reconstruction**: how much hidden geometry to infer versus ask the user to confirm.
